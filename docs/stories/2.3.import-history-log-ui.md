# Story 2.3: Import History Log UI

**Status:** Done
**Epic:** Import Transactions & Stock Accounting
**Created:** 2026-05-23
**Last Updated:** 2026-05-23

## Story

**As a** Farm Manager,
**I want** a transaction feed showing recent incoming shipments,
**so that** I can review suppliers, pricing trends, and batch receipts.

## Acceptance Criteria

1. Given the Transaction History page, When the user clicks the "Imports" tab, Then it must render a chronological table/list of receipts with colored indicators (e.g. Emerald + sign).
2. Given an item in the Import history log, When clicked, Then it must reveal full details including Unit Price, Batch Code, and Expiration Date.

## Tasks

- [ ] Task 1: Create the Unified Transaction History Page Layout (AC: 1)
  - [ ] Implement the new page container at `src/app/history/page.tsx`
  - [ ] Add a sub-navigation header with a standard tab system ("Imports" and "Exports") with smooth slide active state transitions
  - [ ] Ensure layout is fully responsive, leveraging CSS grid structures from `src/styles/layout.css`
- [ ] Task 2: Build the Dynamic Imports History Feed with GenericTable (AC: 1)
  - [ ] Fetch the imported transaction records from `GET /api/imports` using a TanStack Query `useQuery` hook
  - [ ] Bind dynamic data fetching to query key `queryKeys.imports.all`
  - [ ] Populate the table using the `GenericTable` component with structured columns:
    - [ ] **Date:** Formatted using a localized helper (e.g., `YYYY-MM-DD`)
    - [ ] **Material:** Catalog name of the imported item
    - [ ] **Supplier:** Name of the supplying vendor
    - [ ] **Quantity:** Formatted with the material's dynamic unit of measurement (UOM)
    - [ ] **Unit Price:** Formatted as currency
    - [ ] **Total Cost:** Computed product of Quantity * Unit Price
  - [ ] Add an emerald positive indicator (e.g., green text with a "+" sign) to highlight incoming quantities clearly
- [ ] Task 3: Develop the Transaction Details Modal/Drawer Reveal (AC: 2)
  - [ ] Design a premium glassmorphic details pane (modal overlay or side drawer) that triggers on clicking a table row
  - [ ] Include detailed fields in the detail pane:
    - [ ] Expanded Transaction ID / Timestamp details
    - [ ] Supplier Name and Material details
    - [ ] Unit Price, Total Quantity, and computed Total Cost
    - [ ] **Batch Code:** Displayed with high visibility (if present)
    - [ ] **Expiration Date:** Formatted clearly, with special attention/warning highlights if the expiration date is approaching or passed
  - [ ] Support accessible control interactions (Escape key to dismiss details, mouse click outside overlay to close)
- [ ] Task 4: UI Polishing, Loading Skeletons, and Error Catching (AC: 1, 2)
  - [ ] Design and implement CSS-based skeleton loading animations to prevent layout shifts during server-side fetches
  - [ ] Capture async errors gracefully, displaying custom styled warning banners/toasts rather than leaving the screen blank
  - [ ] Ensure full keyboard navigation support and proper ARIA labeling for the history feeds and the details drawer
- [ ] Task 5: QA Verification and Route Integration (AC: 1, 2)
  - [ ] Register `src/app/history/page.tsx` in `docs/architecture/source-tree.json` for compliance
  - [ ] Update the global `Sidebar` or navigation layout with a active link to the `/history` path
  - [ ] Manually test all visual transitions, tab toggles, row clicks, and drawer responsiveness
  - [ ] Ensure all backend test runs remain clean and pass without breaking existing logic

### Data Models

- IImport:
  - `date`: Date (required)
  - `supplierName`: string (required)
  - `materialId`: string (FK -> Material, required)
  - `quantity`: number (required, > 0)
  - `unitPrice`: number (required, > 0)
  - `batchCode`: string (optional)
  - `expirationDate`: Date (optional)
  [Source: docs/architecture/data-models.md]

- IMaterial:
  - `id`: string
  - `name`: string (required)
  - `type`: MaterialType (required)
  - `uom`: string (required)
