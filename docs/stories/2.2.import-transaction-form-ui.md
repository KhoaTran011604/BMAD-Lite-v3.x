# Story 2.2: Import Transaction Form UI

**Status:** Done
**Epic:** Import Transactions & Stock Accounting
**Created:** 2026-05-23
**Last Updated:** 2026-05-23

## Story

**As a** Warehouse Operator,
**I want** a smooth form layout with field suggestions and date-pickers,
**so that** I can log new deliveries rapidly and avoid typing errors.

## Acceptance Criteria

1. Given the Import Form, When selecting a material, Then it must provide a searchable dropdown listing all catalog items.
2. Given chemical materials (e.g. Pesticides, Fertilizers), When logging an import, Then the Expiration Date and Batch Code fields must be marked as highly recommended/required inputs.

## Tasks

- [ ] Task 1: Implement the slide-in QuickActionDrawer Layout Component (AC: 1)
  - [ ] Implement `src/components/QuickActionDrawer.tsx` slide-in panel using custom glassmorphism styles from `src/styles/glass.css`
  - [ ] Setup smooth sliding animations from the right side of the screen using Vanilla CSS transitions
  - [ ] Add an overlay backdrop that is clickable to close the drawer
  - [ ] Support accessible closing via the Escape key, ARIA labeling, and focus trapping
- [ ] Task 2: Build the Import Transaction Form using React Hook Form & Zod (AC: 1, 2)
  - [ ] Define the Zod schema resolver enforcing valid transaction input properties (date, supplierName, materialId, quantity, unitPrice, batchCode, expirationDate)
  - [ ] Create input fields for Supplier Name (text), Quantity (positive number), Unit Price (positive number), and Transaction Date (date-picker defaulting to today)
  - [ ] Add real-time visual error boundaries highlighting fields in glowing red borders and presenting localized helpful alert prompts below invalid elements
  - [ ] Disable the form submit button during pending mutations and render an elegant loader spinner
- [ ] Task 3: Develop the Searchable Catalog Material Dropdown (AC: 1)
  - [ ] Fetch active catalog materials list using TanStack Query `useQuery` targeting key `queryKeys.materials.all`
  - [ ] Implement a searchable dropdown or custom select box with real-time text-input filtering for catalog items
  - [ ] Display the unit of measurement (UOM) dynamically next to the quantity field once a material is selected
- [ ] Task 4: Dynamic Pesticide & Fertilizer Field Validations (AC: 2)
  - [ ] Detect the active material's category type dynamically when a selection is made
  - [ ] If the category matches a chemical type (e.g., `Pesticides` or `Fertilizers`), dynamically adjust the form schema and UI elements:
    - [ ] Add "(Required for Chemicals)" glowing indicators next to Expiration Date and Batch Code labels
    - [ ] Make the inputs required in the Zod validation schema, prompting real-time errors if left empty on submission
- [ ] Task 5: Root Layout Integration and TanStack Query Mutation (AC: 1, 2)
  - [ ] Update `src/app/layout.tsx` to mount the global `QuickActionDrawer` component
  - [ ] Add a global "+ Log Delivery" button in the Layout's header/top navigation to trigger drawer opening
  - [ ] Define TanStack Query `useMutation` targeting `POST /api/imports`
  - [ ] Upon successful submission, trigger TanStack query cache invalidations for:
    - [ ] `queryKeys.imports.all` (updates transaction log feeds)
    - [ ] `queryKeys.materials.all` (updates the Live Dashboard stocks and Catalog counts in real-time)
  - [ ] Bubble success states to close the drawer and clean the form state
- [ ] Task 6: QA Verification and Testing (AC: 1, 2)
  - [ ] Write integration test cases verifying chemical category rules and frontend validation bounds
  - [ ] Test the slide-in drawer's keyboard shortcuts, accessibility properties (tab index, ARIA roles), and responsive touch behaviors
  - [ ] Confirm all tests are green and maintain test coverage at >= 80%

## Dev Notes

### Relevant Files

### Data Models

- IImport:
  - `date`: Date (required)
  - `supplierName`: string (required)
  - `materialId`: string (FK -> Material, required)
  - `quantity`: number (required, > 0)
  - `unitPrice`: number (required, > 0)
  - `batchCode`: string (optional in DB, required if material type is 'Pesticides' or 'Fertilizers')
  - `expirationDate`: Date (optional in DB, required if material type is 'Pesticides' or 'Fertilizers')
  [Source: docs/architecture/data-models.md]

- IMaterial:
  - `id`: string
  - `name`: string (unique, required)
  - `type`: MaterialType ('Seeds' | 'Fertilizers' | 'Pesticides' | 'Tools', required)
  - `uom`: string (required)
  [Source: docs/architecture/data-models.md]

### API Endpoints

- `GET /api/materials` - Fetches catalog materials list to populate searchable selection box
  [Source: docs/architecture/rest-api-spec.md]
- `POST /api/imports` - Records a new incoming supply transaction and increments stock balance
  [Source: docs/architecture/rest-api-spec.md]

### Testing Requirements

- Unit/Integration validation tests: Submitting Pesticides or Fertilizers without Expiration Date or Batch Code must fail on the frontend form layer.
- Unit/Integration validation tests: Submitting Seeds or Tools with empty Expiration Date and Batch Code must pass.
- UX & Accessibility tests: Validate Escape key closure, focus containment inside the active drawer, overlay closing, and smooth CSS transitions.
  [Source: docs/architecture/test-strategy-and-standards.md]

### Coding Standards

- **Complete Type Safety:** Absolute ban on `any`. Strictly bind form fields, query results, and mutation hooks.
- **Dual-Layer Validation:** Ensure client-side Zod validation schemas exactly align with database and API endpoint rules.
- **Decoupled Side Effects:** Keep TanStack Query mutations pure; trigger toast notifications and visual updates exclusively in the form's onSuccess callback function.
  [Source: docs/architecture/coding-standards.md]

### Previous Story Insights

- **TanStack Mutation Invalidation:** Invalidate relevant cache keys upon successful creation to sync stock counts seamlessly across unrelated components without hard reloads.
  [Source: docs/stories/1.3.add-edit-material-catalog-entry-ui.md#dev-record]
- **API Standard Envelopes:** Wrap all API fetch requests and custom mutations with the standardized typed `IApiResponse<T>` interface.
  [Source: docs/stories/1.3.add-edit-material-catalog-entry-ui.md#dev-record]
