# Story 5.2: Shared Formatting Utilities

**Status:** Done
**Epic:** Code Quality, Shared Helpers & Table Alignment Refactor
**Created:** 2026-05-23
**Last Updated:** 2026-05-23

## Story

**As a** Farm Developer,
**I want** a centralized set of datetime and currency formatting functions under a shared utility folder,
**so that** duplicate local formatter functions are eliminated and formatting conventions are consistent across all dashboards and logs.

## Acceptance Criteria

1. Given a datetime formatting helper, When provided with a Date object or ISO string, Then it must return a formatted datetime string including minutes (`YYYY-MM-DD HH:mm`) and handle empty/null inputs gracefully.
2. Given a currency formatting helper, When provided with a numeric amount, Then it must return a US-formatted currency string (e.g. `$1,234.56` or `$0.00`).
3. Given the dashboard or history pages, When displaying date-times or currency values, Then they must import and use the centralized formatting helpers from `src/lib/utils.ts`.

## Tasks

- [x] Task 1: Implement shared formatting utilities in `src/lib/utils.ts` (AC: 1, 2)
  - Write `formatDateTime(date)` supporting minutes formatting (`YYYY-MM-DD HH:mm`).
  - Write `formatCurrency(amount)` for US locale (`en-US`, `USD`, e.g. `$1,234.56`).
- [x] Task 2: Create unit tests to verify correctness of helpers (AC: 1, 2)
  - Create test file `tests/unit/utils.test.ts`.
  - Validate datetime boundary conditions (null, undefined, invalid ISO, standard formats).
  - Validate currency boundary conditions (positive, negative, zero, float fractions).
- [x] Task 3: Refactor UI layouts to utilize central formatting helpers (AC: 3)
  - Refactor `src/app/page.tsx` (remove local `currencyFormatter`, `quantityFormatter`, and `formatTransactionDate` duplicate definitions).
  - Refactor `src/app/history/page.tsx` (remove local `formatDate` and `formatCurrency` duplicates).
  - Import and apply new centralized helpers codebase-wide.
