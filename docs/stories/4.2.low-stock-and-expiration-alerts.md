# Story 4.2: Low-Stock and Expiration Alerts

**Status:** Approved
**Epic:** Live Inventory & Smart Alerts Dashboard
**Created:** 2026-05-23
**Last Updated:** 2026-05-23

## Story

**As a** Farm Manager,
**I want** automated priority indicators for expiring or depleted materials,
**so that** I can purchase replacements before planting schedules are affected.

## Acceptance Criteria

1. Given a material with stock level below its threshold, When the dashboard renders, Then it must place this item at the top of the "Low Stock Warnings" card with a glowing amber badge.
2. Given an imported batch expiring within 30 days of the current date, When the dashboard renders, Then it must trigger a "Near Expiry Alert" displaying the days remaining and batch code in red.

## Tasks

- [x] Extend the dashboard data layer to derive low-stock materials from `currentStock` and `safetyStock`, sorted so the most urgent shortages appear first. (AC: 1)
- [x] Build near-expiry alert aggregation from import batches with `expirationDate`, calculating days remaining relative to the current date. (AC: 2)
- [x] Implement dashboard alert cards in `src/app/page.tsx` with clear visual priority, amber low-stock badges, red expiry indicators, and empty-state messaging. (AC: 1, 2)
- [x] Reuse existing query infrastructure so alert cards refresh reactively after import and export mutations invalidate cached data. (AC: 1, 2)
- [x] Add user-friendly loading and error states for alert sections, consistent with project accessibility and UX requirements. (AC: 1, 2)
- [x] Add unit and integration tests covering alert prioritization, expiry window calculation, and dashboard rendering behavior. (AC: 1, 2)

### API Endpoints

- `GET /api/materials` - Provides the live stock inventory data used to identify threshold breaches. [Source: docs/architecture.md#rest-api-spec]
- `GET /api/imports` - Provides import batches sorted by date descending, including expiration dates used for expiry warning detection. [Source: docs/architecture.md#rest-api-spec]
- `GET /api/exports` - Impacts stock balances and therefore the low-stock alert state after disbursements. [Source: docs/architecture.md#rest-api-spec]
