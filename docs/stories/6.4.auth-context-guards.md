# Story 6.4: Auth Context & Client-Side Navigation Guards

**Status:** Done  
**Epic:** User Authentication & Role-Based Access Control (RBAC)  
**Created:** 2026-05-23  
**Last Updated:** 2026-05-23  

## Story
**As a** Farm Manager,  
**I want** the client app to guard private pages and dynamically alter navigation options based on the user's active session,  
**so that** unauthenticated visitors are prevented from inspecting inventory, and roles are visually reflected.

---

## Acceptance Criteria
1. **Given** the application load lifecycle, **When** initialized, **Then** it must execute a background `/api/auth/me` request to hydrate the client-side `AuthContext` state.
2. **Given** private routes (`/`, `/catalog`, `/history`), **When** visited by an unauthenticated browser, **Then** the application must instantly redirect the user to `/login`.
3. **Given** an authenticated user accessing the application, **When** rendering the `Sidebar` navigation, **Then** it must display the user's `username` alongside a visual role badge (`Manager` / `Worker`) and expose a clear "Logout" action.

---

## Tasks
- [x] **Task 1: Build Client AuthContext Provider (`src/context/auth.tsx`)**
  - Define `AuthContextType` including `user` object (username, role), `isAuthenticated`, `isLoading`, `login()`, `logout()`, `register()`.
  - Fetch user session on mount via `/api/auth/me`.
  - Wrap top-level App Layout (`src/app/layout.tsx`) in the provider.
- [x] **Task 2: Implement Next.js Navigation Middleware (`src/middleware.ts`)**
  - Read session cookie.
  - Redirect unauthenticated users navigating to private paths (`/`, `/catalog`, `/history`) straight to `/login`.
  - Redirect authenticated users visiting `/login` or `/register` to the Dashboard (`/`).
- [x] **Task 3: Refactor Sidebar (`src/components/Sidebar.tsx`)**
  - Hook into `AuthContext` to display the active username and role badge.
  - Implement a premium and well-positioned "Logout" button invoking the context logout handler.
