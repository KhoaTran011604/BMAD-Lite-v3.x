## How to Use This Graph

**When adding a new feature:**
1. Identify which module(s) in the graph are affected.
2. Follow the arrows to find related modules that may need updates.
3. Read the related stories to understand existing patterns and decisions.
4. Check `source-tree.json` for exact file paths in those modules.

**Example**: Adding a new transaction field (e.g., "discount")?
-> Look at `IMPORTS` or `EXPORTS` subgraphs -> affects `Import Logging` or `Export Logging` components and DB schemas.
-> Needs: Schema changes in `Import.ts`/`Export.ts`, form schema update in `QuickActionDrawer.tsx`, and table display update in `history/page.tsx`.
-> Read stories `2.2`, `2.3`, `3.2`, `3.3` for established form/table patterns.
