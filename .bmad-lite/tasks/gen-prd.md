# Generate PRD Docs Task

Generate PRD (Product Requirements Document) from scan results.
Referenced from `.bmad-lite/agents/scanner.md`.

---

## Prerequisites

- `*scan-prd` or `*scan` must be completed first
- Scan data available: config, modules, business, routes

## Template

Uses PRD section structure from `.bmad-lite/templates/prd.yaml` as reference for file naming and structure.

## Output Files

```
docs/prd/
  index.md                        # TOC with links
  goals-and-background-context.md # [SCANNED] from README/package.json/CLAUDE.md
  requirements.md                 # [SCANNED] FRs from routes, NFRs from config
  epic-list.md                    # [SCANNED] epic titles + goals summary
  epic-{n}-{slug}.md              # [SCANNED] one file per inferred epic
  user-interface-design-goals.md  # [SCANNED] from UI page/component names
  technical-assumptions.md        # [SCANNED] from tsconfig/next.config/package.json
```
